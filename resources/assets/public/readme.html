操作说明

HOLD为鼠标右键；DRAG为摇杆键，可以控制游戏角色移动与游戏选项光标移动等操作；

Cancel为回退键，可以在游戏中调出菜单选项，部分游戏读档后需要点击此按键以恢复控制操作；

↵为确定键，可用于进入游戏与点击确定等重要功能；

⚙️为其他功能按键，可进行其他功能，如开启或关闭全屏（隐藏按键），开启或关闭鼠标操作，F8改变显示信息等功能。

另外，webview环境不支持下载Save存档文件夹，加载至Save文件夹与下载许可证功能，此功能仅启用服务器端口的浏览器支持。
